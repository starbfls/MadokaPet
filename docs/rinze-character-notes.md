# 凛世：角色与台词依据

本项目中的中文短句全部为桌宠场景创作，不是官方游戏台词，也不是官方剧情的中文翻译。没有搬用剧情对话、歌词或将玩家解读作为官方设定。Snow Magic 是外观参考，不据此编造一段同名官方剧情。

## 剧情脉络的辅助核对

下面为玩家对原游戏剧情的回顾或感想，属于二手资料，不是官方文本。

- [W.I.N.G. 剧情回顾](https://note.com/sakurapenguin02/n/nd898721dfafb)：从与制作人的相遇与报恩之心，逐渐看见粉丝的支持，拓宽作为偶像的视野。
- [《をとめ大学》剧情回顾](https://kinakomochimoch.hatenablog.com/entry/2019/12/03/223746)：与智代子谈论少女漫画及故事人物的趣味。
- [《ロー・ポジション》《凛世花伝》等剧情阅读记录](https://note.com/4021_note/n/nd687dc7ae3ee)：用于辅助把握日常细节、表达心意的迟疑；不将文章中的戏谑评论写入角色设定。

## 写作约束

- 中文以“凛世”自称，称呼用户“制作人先生”，用礼貌措辞和适量停顿表达慢而郑重的语气。
- 待机内容包含练习、伙伴、舞台、少女漫画、尝试新事物与主动表达；避免只写成被动等待或一味自责的角色。
- 温柔、含蓄，也保留自己的兴趣与行动意愿。不把“制作人的话都是命令”、夸张嫉妒或网络梗当成角色的全部。
- 用量、刷新、拖动等为桌宠原创情境；不声称这些情境出现在官方剧情。
- 主题采用参考图的淡蓝与雪白、深蓝文字。属于本项目的可读性配色，不声称每个色值都是官方指定色。
